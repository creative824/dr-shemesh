# אתר ד״ר הנרי שמש

אתר סטטי (HTML/CSS/JS, בלי ספריות), בנוי לפי המוקאפ. מתאים להעלאה ל־GitHub Pages כמו שהוא.

## קבצים
- `index.html` מבנה העמוד
- `styles.css` עיצוב (משתני צבע וגופן בראש הקובץ)
- `content.js` **כל התוכן שמתעדכן**: שירותים, פרטי קשר, תמונות, אינסטגרם, סרטוני מטופלים, כתובת שליחת טפסים
- `app.js` התנהגות: תפריט, חלונות, קרוסלה, טפסים, פיד אינסטגרם
- `assets/` תמונות. **תמונות אמיתיות: hero, about-doctor, about-clinic. כל השאר תמונות דמה מהמוקאפ.** להחליף בקבצים באותו שם, או לעדכן את הנתיב ב־`content.js`.

## אינסטגרם (פיד חי)
מוצגת ההטמעה הרשמית של פרופיל האינסטגרם (`instagram.com/dr_shemesh1/embed`), בלי הרשמה ובלי חיבור חשבון. הפוסטים מתעדכנים לבד.
להחלפה לרשת פוסטים קבועה: `instagram.mode = "grid"` ב־`content.js`.

## עוד עדכונים
- **לוגו**: להחליף את `brand-mark` ב־`index.html` בתגית `<img>` (יש הערה במקום).
- **סרטוני מטופלים**: בכל פריט ב־`stories` למלא `video` (mp4) ו־`poster`. רק באישור בכתב מהמטופל.
- **סרטון בראש העמוד**: `heroVideo`. ריק = הכפתור מוביל לסרטוני המטופלים.
- **טפסים**: להגדיר `formEndpoint` (למשל Formspree). עד אז הטופס במצב תצוגה מקדימה ולא שולח.
